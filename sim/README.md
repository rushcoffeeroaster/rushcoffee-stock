# Rush Hour — แอปจำลองขยายสาขา (ประชาชื่น)

แอปมือถือแบบติดตั้งลงหน้าจอโฮมได้ (PWA) คำนวณทุกอย่างในเครื่อง ไม่ต่อหลังบ้าน ไม่ต้องใช้เน็ตหลังเปิดครั้งแรก

## ไฟล์ในชุดนี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (สูตร กราฟ หน้าตา อยู่ในไฟล์เดียว) |
| `manifest.webmanifest` | ทำให้ Android/Chrome ขึ้นปุ่ม "ติดตั้งแอป" |
| `sw.js` | Service worker — แคชไว้ให้เปิดได้ตอนไม่มีเน็ต |
| `icon-192.png` `icon-512.png` `apple-touch-icon.png` `favicon-32.png` | ไอคอนหน้าจอโฮม |
| `.nojekyll` | บอก GitHub Pages ไม่ต้องประมวลผลไฟล์ |

## วิธีขึ้น GitHub Pages (แบบเดียวกับหน้าอื่นในแอป Rush)

1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้เข้า repo — จะวางไว้ใน root หรือโฟลเดอร์ย่อยเช่น `sim/` ก็ได้
2. Settings ▸ Pages ▸ เลือก branch ที่ใช้ (ปกติ `main`) แล้ว Save
3. รอสักครู่ แล้วเปิด `https://<username>.github.io/<repo>/sim/`

ต้องเป็น **HTTPS** เท่านั้น service worker ถึงจะทำงาน — GitHub Pages เป็น HTTPS อยู่แล้ว

## วิธีติดไอคอนลงหน้าจอโฮม

**iPhone (Safari)** — เปิดลิงก์ ▸ ปุ่มแชร์ ▸ "เพิ่มไปยังหน้าจอโฮม"
**Android (Chrome)** — เปิดลิงก์ ▸ เมนู ⋮ ▸ "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"

เปิดจากไอคอนแล้วจะเต็มจอ ไม่มีแถบเบราว์เซอร์

## หมายเหตุเรื่องข้อมูล

สถานการณ์ที่เซฟและค่าที่ตั้งไว้ล่าสุด เก็บใน `localStorage` ของเครื่องนั้นเท่านั้น — ไม่ได้ส่งขึ้นคลาวด์ ไม่ซิงก์ข้ามเครื่อง
ถ้าล้างข้อมูลเบราว์เซอร์หรือถอนแอป ข้อมูลจะหาย

## สูตรหลักที่ใช้

- **ลำดับดีล** 1 Rush PHS (หุ้น 40%) · 2 Rush Hour เซ็นทรัลพิษณุโลก (30%) — เปิดอยู่แล้วทั้งคู่ · 3 MiNCE (40%) · 4 ประชาชื่น (50% ดีลกับดารา) · 5 ขึ้นไป (100%)
- **กำไรเข้ากอง** = กำไรเต็มของแต่ละธุรกิจ × % หุ้นของคุณ × สัดส่วนที่เก็บไว้ขยาย
- **เงินลงทุนต่อสาขา** หักจากกองเต็มจำนวน (เป็นทุนที่กิจการต้องมี ไม่ได้หารตามหุ้น)
- **ประชาชื่น** ล็อกวันเปิดไว้ ไม่รอกองครบ · กำไรเต็ม 3 เดือนแรก แล้วลด 20% ในเดือน 4–6 แล้วลดอีก 10% ตั้งแต่เดือน 7 จากนั้นคงที่
- **MiNCE** กำไรเต็ม = รายได้ × 0.74 − 84,000 (วัตถุดิบ 26% + คงที่)
- **Rush Coffee Roaster** กำไร = ยอดขายส่งเดือนนั้น × GP% − ต้นทุนทีม โดยยอดโตเป็น % ต่อเดือนจนชนเพดานกำลังผลิต
- เดือนที่ 1 = ก.ค. 2569

## ข้อควรระวัง

ตัวเลขกำไร Rush PHS ตั้งค่าเริ่มต้นไว้ 50,000 ฿/เดือนเป็นค่าสมมติ — รายงานภาค 1–4 ยืนยันเฉพาะสาขาเซ็นทรัลพิษณุโลก (76,000 ฿) ปรับให้ตรงของจริงก่อนใช้ตัดสินใจ

โมเดลหักค่าเปิดประชาชื่นจากกองของคุณเต็มจำนวน แต่กำไรเข้าคุณตาม % หุ้น — ถ้าหุ้นส่วนออกเงินด้วย ให้ลดสไลเดอร์ "งบเปิด" ตามสัดส่วนที่คุณออกจริง
